# Anjali Super Salon and Training Centre

Ladies salon and beauty training website in Abhayapuri, Assam.

## Pages
Home, Services, Training, About and Contact.

## Preview locally
Run `python3 -m http.server 8000 --directory dist` and open http://localhost:8000.

## Deploy on Vercel
Import this repository. Use Framework Preset **Other**, leave the build command empty, and set Output Directory to **dist**. The included vercel.json provides the static output settings. No npm install is required.

## Customise
- `build.py`: page copy, service catalogue and sample prices; run `python3 build.py` after changes.
- `dist/assets/app.js`: WhatsApp messages, enquiry form and animations.
- `dist/assets/style.css`: colours, typography, spacing and responsive layouts.
- `dist/assets/stylist.webp`: generated editorial hero portrait.
